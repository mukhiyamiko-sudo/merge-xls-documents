# 合并文档需求文档

> 历史文档：本文记录早期版本，不再作为开发或验收依据。V1—V4 只是问题修复与交互完善过程；请仅按 [V5 最终 PRD](PRD-V5.md) 复现最终程序。

版本：2.0
日期：2026-10-09

## 1. 目标

制作一个无需安装 Microsoft Excel、可双击运行的 Windows 单文件 EXE。用户拖入一个文件夹后，软件自动识别该文件夹第一层的 `.xls` 文件，校验结构，按文件名从小到大合并明细，并生成新的标准 `.xls` 文件。

## 2. 输入规则

- 一次处理一个文件夹，只扫描第一层，不扫描子文件夹。
- 只识别 `.xls` 文件。
- 兼容两种实际格式：标准 Excel 97-2003 二进制工作簿，以及扩展名为 `.xls` 的 HTML 表格。
- 文件按文件名从小到大排序。
- 固定表头为 10 列：`CODE`、`DESCRIPTION`、`ITEM #`、`ITEM DESCRIPTION`、`UPC`、`MODEL #`、`UNIT COST`、`CLAIM QTY`、`UOM`、`CLAIM AMT`。
- 表头不一致的文件视为异常并跳过。
- 每个源文件底部必须完整包含以下五项汇总，否则跳过并提示需要手动处理：
  - `TOTAL QUANTITY`
  - `TOTAL FOR CLAIM #`
  - `TOTAL FREIGHT FEE`
  - `TOTAL HANDLING COST`
  - `TOTAL DISPOSAL FEE`

## 3. 合并规则

- 只保留第一行表头。
- 删除每个源文件的空白分隔行和底部五项汇总。
- 按文件顺序纵向追加全部有效明细。
- 保持固定 10 列结构，输出样式参考第一个有效文件和用户提供的 `111.xls`。
- 原始文件不修改、不覆盖。
- 合并总行数不得超过旧版 `.xls` 的 65,536 行上限。

## 4. 输出规则

- 输出保存到拖入的源文件夹。
- 文件名格式：`合并结果_YYYYMMDD_HHMMSS.xls`。
- 若同一秒内重名，自动追加序号。
- 已生成的 `合并结果_*.xls` 永不参与再次合并。
- 如果检测到历史合并结果，先弹窗提醒；用户确认继续后，排除历史结果并正常处理原始文件。

## 5. 界面和交互

- 软件名称：合并文档。
- 支持拖入文件夹，也支持“选择文件夹”按钮。
- 选择或拖入文件夹后只扫描第一层的 `.xls`，显示文件数量，不自动合并。
- 用户确认文件数量后，必须点击“开始合并”按钮才执行校验与合并。
- 显示进度条、当前完成数和文件总数。
- 提供“取消”按钮。取消后不保留不完整结果。
- 窗口下方显示可滚动运行日志，记录成功、跳过、错误、取消和输出路径。
- 提供“清空日志”按钮。
- 合并完成后不自动打开目录；“打开所在文件夹”按钮变为可用，点击后打开目录并选中生成文件。
- 完成一次后软件保持打开，可直接处理另一个文件夹。

## 6. 异常处理

- 单个文件打不开、结构错误、表头不一致或汇总不完整时，跳过该文件并继续处理其他文件。
- 日志必须显示异常文件名和具体原因。
- 若没有任何有效文件，则不生成结果并明确提示。
- 输出先写入临时文件，全部成功后再替换为正式文件，避免留下损坏或半成品结果。

## 7. 验收标准

- 四个样本文件合并后得到 1 行表头和 86 行明细，共 87 行，与 `111.xls` 的数据顺序一致。
- 输出中不包含五项底部汇总。
- 文件顺序严格按文件名从小到大。
- 异常文件不阻塞其他有效文件。
- EXE 在未安装 Microsoft Excel 的 Windows 电脑上可运行。
- EXE 双击启动时不显示命令行窗口。
- 拖放、选择文件夹、进度、取消、日志清空和打开所在文件夹功能均可用。
- 拖放或选择文件夹不会自动合并；开始按钮是唯一的合并入口。
